# Релиз: Steam, маркетинг, чек-лист «игра от А до Я»

← [База знаний](README.md)

## Steam: порядок действий
1. Steamworks Partner, взнос Steam Direct ($100 за игру, возвращается после $1000 дохода).
2. **Страница «Скоро выйдет» — как можно раньше.** Вишлисты копятся с открытия страницы,
   и именно страница конвертирует: по опросу Zukowski (февраль 2025), 68–88% вишлистов
   с фестиваля пришли от людей, не игравших в демо.
3. Страница проходит проверку Valve (несколько рабочих дней), «Скоро выйдет» должна провисеть
   минимум 2 недели до релиза. Билд тоже проверяется перед релизом.
4. Демо — **заранее, до Next Fest**, а не в первый день фестиваля. Вишлисты до фестиваля —
   лучший предиктор результата на фестивале.
5. Релиз со скидкой запуска, патч по первым отзывам в первые дни.

## Страница
- **Маленькая капсула** важнее всех: она в поиске и списках. Отдельная композиция под мелкий
  размер: крупное название, заполненный кадр, без мелких деталей. Проверять в реальном
  размере. Без оценок и наград на капсуле.
- Размеры: header 920×430, small 462×174, main 1232×706, vertical 748×896, library 600×900,
  library hero 3840×1240 + логотип. Сверять с актуальными требованиями Steamworks.
- **Трейлер: геймплей в первые 5 секунд.** Без логотипа студии и медленных пролётов в начале.
  Steam нарезает микротрейлер из шести 1-секундных фрагментов по всему ролику, так что
  геймплей нужен по всей длине.
- Короткое описание: **жанр в первых 10 словах** («Бумер-шутер на скорость, где кровь — топливо…»).
- **Все 20 тегов**, конкретные поджанры вперёд (Boomer Shooter, Fast-Paced, Movement Shooter,
  Retro FPS, Gore, Speedrunning), общие (Indie, Action) не наверх.
- Скриншоты 1920×1080, реальный геймплей, первые 4 — самые сильные.
- Капсулу рисовать с оглядкой на топ жанра: задача — сразу считываться фанатом бумер-шутеров.

## Next Fest
- Проходит трижды в год (февраль, июнь, октябрь; октябрьский 2026 — 12–19 октября).
- Медиана по опросу 182 разработчиков (февраль 2026) — около 800 вишлистов за неделю. Числа
  самоотобранные, это ориентир.
- Демо — 15–30 минут лучшего контента, с призывом добавить в вишлист на экране конца.

## Жанровый путь
- Сообщество бумер-шутеров плотное: профильные кураторы и ютуберы, издатели ретро-шутеров
  (New Blood, Slipgate/3D Realms, Fulqrum). Демо и клипы с механикой (кровавый сёрф на 25 м/с)
  продают лучше описаний.
- Короткие вертикальные клипы самых зрелищных моментов — стандартный канал вишлистов.

## Лидерборды (Steam через GodotSteam)
- Отдельная таблица на уровень, сортировка по возрастанию (время), метод загрузки «оставлять лучшее».
- Время хранить в **миллисекундах целым** числом.
- `details` (до 64 int) — метаданные забега: версия сборки, рейтинг, BPM-пик, смерти, контрольная сумма.
- К записи можно прикрепить UGC-файл (`attachLeaderboardUGC`) — **реплей/призрак**.
- **Steam ничего не проверяет**: таблица обновляется сразу после загрузки. Защита:
  - проверка правдоподобия на клиенте (минимально возможное время уровня, все секторы зачищены);
  - новая таблица на версию, если патч меняет маршруты;
  - реплеи топа для ручной проверки; удаление записей через Steamworks;
  - раздельные таблицы для модов/читов, если они есть.
- Тестовый App ID 480 (Spacewar) для разработки (решение уже в `docs/bpm.md`).

## Чек-лист «игра от А до Я»
**Ядро**
- [ ] Ядро весело в блокауте без арта (подтверждено посторонними)
- [ ] Вертикальный срез: один уровень финального качества
- [ ] Весь контент: уровни, враги, оружие, финал

**Отклик и подача**
- [ ] У каждого действия игрока есть звук + визуал (+ камера для крупного)
- [ ] У каждой атаки врага есть визуальный и звуковой телеграф
- [ ] Настоящие звуки, микс, шины, лимит голосов
- [ ] Музыка (адаптивная — по возможности)
- [ ] Единый художественный стиль, читаемость силуэтов

**Структура**
- [ ] Главное меню, пауза, выбор уровня, экран конца уровня
- [ ] Мгновенный рестарт
- [ ] Обучение делом (первые минуты)
- [ ] Сохранение прогресса и лучших результатов
- [ ] Финал и титры

**Настройки и доступность** (см. [ui-ux.md](ui-ux.md))
- [ ] Чувствительность, FOV, переназначение клавиш, громкости, графика
- [ ] Комфорт: тряска, наклон, вспышки
- [ ] Уровни сложности
- [ ] Всё сохраняется между запусками
- [ ] Геймпад (Steam Deck)

**Техника**
- [ ] Стабильные FPS на целевом минимуме (и на Steam Deck)
- [ ] Нет утечек при долгой игре и многократном рестарте
- [ ] Лог ошибок в `user://` для баг-репортов
- [ ] Отладочные клавиши выключены в релизной сборке
- [ ] Разные разрешения, соотношения сторон, мониторы 60/144 Гц

**Релиз**
- [ ] Страница Steam, капсулы, трейлер, скриншоты, теги
- [ ] Демо до Next Fest
- [ ] Лидерборды, достижения (по желанию), облачные сохранения
- [ ] Пресс-кит, рассылка кураторам и ютуберам
- [ ] План патчей после релиза

## Применительно к VOIDKILL
- Из чек-листа уже есть: ядро механик, каркас уровней с экраном конца и рейтингом, рестарт
  с чекпоинта (R), полоски HP как отладка.
- Нет: меню, настроек, сохранений, настоящего звука и музыки, обучения, финальных уровней,
  Steam-интеграции. Это и есть путь от текущего состояния до релиза.
