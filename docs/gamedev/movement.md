# Движение в шутере от первого лица

← [База знаний](README.md)

## Математика Quake/Source
Распрыжка и стрейф-джамп — следствие того, **как** ограничивается ускорение. Предел скорости
проверяется по **проекции** скорости на желаемое направление (`wishdir`), а не по полной скорости.

```
# Ускорение (PM_Accelerate). Одна функция на земле и в воздухе, разные accel и wishspeed.
func accelerate(vel, wishdir, wishspeed, accel, dt):
	var current = vel.dot(wishdir)            # скорость вдоль желаемого направления
	var add = wishspeed - current
	if add <= 0.0:
		return vel
	var a = min(accel * wishspeed * dt, add)  # не больше, чем нужно до wishspeed
	return vel + wishdir * a

# Трение (PM_Friction), только на земле
func friction(vel, friction, stopspeed, dt):
	var speed = vel.length()
	if speed < 0.001:
		return Vector3.ZERO
	var control = max(speed, stopspeed)       # малые скорости гасятся быстрее
	var newspeed = max(speed - control * friction * dt, 0.0)
	return vel * (newspeed / speed)
```

- Если `wishdir` почти перпендикулярен скорости, `current ≈ 0`, и каждое приращение
  добавляется целиком: модуль скорости растёт сверх `wishspeed`. Отсюда разгон стрейфом.
- **Распрыжка (bhop)** работает, потому что трение применяется только на земле. Прыжок в кадр
  приземления пропускает трение, и скорость сохраняется.
- В воздухе Quake/Source режут `wishspeed` (в Source — до 30 юнитов/с), но дают большой
  `airaccelerate`: поворот скорости силён, прямой разгон слаб.
- **CPM** (Challenge ProMode) добавляет air control: при зажатом «вперёд» без стрейфа вектор
  скорости поворачивается к взгляду без потери модуля.
- Масштаб: игрок в Quake ~32 юнита шириной и ~56 высотой, 1 юнит ≈ 3 см. `sv_maxspeed 320`
  ≈ 10 м/с — ровно `WALK_SPEED` VOIDKILL.

## Отзывчивость
- **Coyote time** — прыжок ещё доступен короткое время после схода с края (ориентир 0.08–0.15 с).
- **Буфер прыжка** — нажатие незадолго до приземления исполняется при касании (0.1–0.15 с).
- **Буфер других действий** — то же для рывка, слэма, мили: нажатие во время недоступности
  исполняется, как только действие стало доступно (в разумном окне).
- **Угловой допуск** — подталкивание игрока вверх, если он чуть задел край уступа головой или
  ногами. Без этого «прилипает» к краям.
- **Ступени** (`step height`) — подъём на мелкие препятствия без прыжка. У `CharacterBody3D` своих
  ступеней нет, их делают кастом (луч/`test_move`) или пологими коллайдерами.

## Набор приёмов и их роли
| Приём | Роль | Типичные ограничения |
|---|---|---|
| Распрыжка / стрейф | Накопление скорости мастерством | Предел скорости, окно прыжка |
| Рывок (dash) | Уклонение, рывок к цели | Заряды + восстановление |
| Слайд | Сохранение скорости, проход под препятствием | Трение, длительность |
| Бег по стене | Связь пролётов, вертикаль | Длительность, сползание, запрет повторной стены |
| Слэм / ground pound | Вход в бой сверху, контроль толпы | Высота, кулдаун |
| Крюк, батут | Вертикаль, быстрые переходы | Точки привязки на уровне |

- Каждый приём должен **сохранять или преобразовывать** импульс, а не обнулять его. Приём,
  который останавливает игрока, в скоростной игре используют редко.
- Связки (слайд → прыжок → бег по стене → рывок) — источник глубины. Проверять, что переходы
  не теряют скорость случайно (из-за порядка применения трения и прыжка в кадре).
- Порог «мастерства»: базовое прохождение без распрыжки, рекорды — с ней.

## Метрики
Метрики движения задают уровень (см. [levels-encounters.md](levels-encounters.md)):
- Высота и дальность прыжка с места, с разбега, с рывком, с бега по стене.
- Максимальная преодолимая пропасть на каждом уровне скорости.
- Время полного разворота при стрейфе (сколько метров нужно, чтобы развернуться на скорости).
- Минимальная ширина прохода, где можно сохранить скорость.

Держать эти числа в одной таблице (в `docs/movement.md`) и пересчитывать после правки
параметров. Отладочный режим: след траектории прыжка, вывод скорости, высоты и состояния.

## Камера при движении
- Мышь — в `_input`/`_unhandled_input`, поворот применяется сразу, без сглаживания (любое
  сглаживание мыши — задержка).
- Наклон и покачивание (head bob) — малые, отключаемые.
- При включённой интерполяции физики камера позиционируется по интерполированной позиции
  тела (см. [godot.md](godot.md)).

## Применительно к VOIDKILL
- В `docs/movement.md` есть bhop-окно 0.12 с, coyote 0.12 с, буфер 0.12 с, air-strafe в стиле
  Quake/Source, рывки, слайд, бег по стене. Это полный современный набор.
- Чего нет в документе: таблицы метрик (дальность прыжка на скоростях 10 / 14.5 / 25 м/с). Её
  стоит снять до постройки настоящих уровней (п.28.1).
