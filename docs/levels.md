# Уровни: формат игры

← [Оглавление: DESIGN.md](../DESIGN.md)

> Статус: **Запланировано, не реализовано.** Сейчас в игре есть только тестовая арена
> (`test_arena.tscn`, см. [test-arena.md](test-arena.md)), смерть перезапускает всю сцену
> (`GameManager.restart_game()`).

## Формат
- **Линейные уровни на зачистку.** Ориентир — Ultrakill.
- **Уровень — цепочка секторов без пауз.** Зачистил сектор до последнего врага — перегородка
  падает — сразу следующий сектор.
- **Интенсивность секторов чередуется**: тяжёлый, потом полегче — передышка без выхода из боя.

## Кровавая перегородка
- Стена из крови между секторами: стекающая кровь, **полупрозрачная** — следующий сектор и его
  врагов видно заранее.
- **Пульсирует в такт сердцу игрока** (BPM).
- Ориентир по роли — туманные двери Dark Souls, но в стилистике игры.
- **При зачистке сектора** стена обрушивается и растекается, оставляя **лужи крови на пороге** —
  игрок может сёрфить по ним прямо в следующий сектор (кровавый сёрф, см. [movement.md](movement.md)).
- **Каждая перегородка — чекпоинт.** Сейчас смерть перезапускает всю сцену; с секторами рестарт
  должен возвращать к последней пройденной перегородке.

## Масштаб арен
- Уровни **крупнее, чем в Ultrakill**: мувмент быстрее, и скорость растёт с BPM
  (~14.5 → 25 м/с, `get_current_max_speed()`, см. [bpm.md](bpm.md)).
- Арены проектируются **под верхнюю скорость**. Мерка — **время пересечения на полной скорости**,
  а не метры.
- **Вертикаль вместо площади**: объём набирается высотой (ярусы, шахты, wallrun-стены), а не
  растягиванием пола.

## Рейтинг в конце уровня
- Экран конца уровня с рейтингом по: **времени**, **убийствам**, **полученному урону**,
  **времени в OVERDRIVE**.
- Это дом для «очков» из roadmap (раздел «Очки и лидерборд» в [bpm.md](bpm.md), множитель
  `BPM / 100`) и будущего лидерборда.

## Нужен каркас
- **Секторы** — границы, список врагов сектора, условие зачистки (последний враг убит).
- **Перегородки** — кровавая стена между секторами: визуал, пульсация, обрушение, лужи на пороге.
- **Волны внутри сектора** — враги сектора появляются волнами, а не все сразу.
- **Чекпоинты** — сохранение прогресса на каждой перегородке, рестарт с последней.
- **Экран конца уровня** — рейтинг.

## Открытые вопросы
- **Реакция врагов на скорости.** Радиус обнаружения врагов 25 м (`DetectionArea`) на полной
  скорости (25 м/с) пересекается примерно за секунду. Проверить, успевают ли враги реагировать
  (`reaction_delay` 0.4 с, телеграфы атак) — или игрок пролетает сектор раньше, чем враги
  включаются.
